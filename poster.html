Introduction

Higher education institutions manage voluminous, constantly updated documentation—spanning attendance mandates, grading policies, fee structures, hostel curfews, and academic schedules. Traditional student helpdesks incur significant queue times and rely on manual triage.

The AI-Powered College Helpdesk & Student Assistant is an intelligent, full-stack web platform developed using FastAPI, Streamlit, LangChain, ChromaDB, and the Groq LPU (Llama 3.3 70B). It delivers instant, citation-backed answers grounded strictly in official college documents with near-zero latency and verifiable provenance.

Methodology

The system operates through an orchestrated 5-stage pipeline:

  • Document Ingestion: Page-by-page text extraction via PyMuPDF; normalized and split via Recursive Character Chunking (1,000 chars, 200 overlap).
  • Deterministic Vector Embeddings: 384-dimensional dense semantic hashing embeddings stored with document metadata in ChromaDB.
  • Hybrid Retrieval: Merges top-k vector similarity candidate pools with sparse BM25 keyword re-ranking.
  • Grounded LLM Generation: Strict system prompts restrict responses exclusively to retrieved context chunks, preventing policy hallucinations.
  • Tool Intent Router: Keyword and agent routers dispatch queries across RAG search, relational timetable lookup, notices, and FAQs.

Project Objectives
  • Deploy a 24/7 conversational assistant for autonomous student query resolution.
  • Eliminate generative hallucinations by mandating strict source citation (Document Name & Page).
  • Implement hybrid dense-sparse retrieval for accurate handling of academic codes and policies.
  • Provide an administrative command dashboard for PDF upload, timetable schedule editing, and analytics.
  • Achieve sub-second inference latency through high-throughput Groq LPU acceleration.
Conclusion

The AI-Powered College Helpdesk bridges the institutional information gap. By combining grounded Retrieval-Augmented Generation with multi-tool relational routing, the system guarantees 100% factual accuracy with transparent citations, drastically reducing administrative burden while enhancing the student learning environment.
